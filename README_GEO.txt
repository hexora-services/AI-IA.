AI IA (აი ია) — 0.1 საცდელი ვერსია
================================
პროექტი: ხმოვანი პერსონალური ორგანიზატორი + პირადი/სამუშაო ფინანსები.

რა მუშაობს:
- შეხვედრების/შეკვეთების დამატება, რედაქტირება და დასრულება.
- მისამართის გახსნა Google Maps-ში.
- შემოსავლის, ხარჯების და ვალების აღრიცხვა (პირადი/სამუშაო ცალ-ცალკე).
- თანხების შეჯამება დღის/თვის მიხედვით, GEL / USD / EUR ცალ-ცალკე.
- ქართულის, ინგლისურისა და რუსულის ინტერფეისი.
- ბრაუზერის ხმოვანი ამოცნობა, სადაც SpeechRecognition მხარდაჭერილია.
  ამოცნობილი მარტივი წინადადებიდან წინასწარ ივსება ფორმა.
  ყოველი ჩანაწერი მომხმარებელმა უნდა გადაამოწმოს და შეინახოს.
- აპლიკაციის მუშაობისას დროის შეხსენებები (ბრაუზერის ნებართვით).
- JSON ფაილში სარეზერვო ასლის ჩამოტვირთვა/აღდგენა.
- HTTPS საიტზე PWA სახით დაყენება; ძირითადი გვერდები ოფლაინ იხსნება.

როგორ ატვირთო GitHub Pages-ზე:
1. GitHub-ზე შექმენი ახალი public repository, მაგალითად ai-ia.
2. ამ ZIP-ის შიგნით არსებული ფაილები და icons საქაღალდე ატვირთე
   რეპოზიტორიის მთავარ (root) დონეზე. თვით ZIP არ ატვირთო.
3. Settings > Pages > Build and deployment > Deploy from a branch.
4. Branch: main, Folder: / (root) > Save.
5. რამდენიმე წუთში მისამართი იქნება: https://USERNAME.github.io/ai-ia/
6. Android Chrome-ში გახსენი საიტი და მენიუდან Add to Home screen/Install app.

მნიშვნელოვანი შეზღუდვები:
- ჯერ არ გვაქვს რეალური AI სერვერი/მოდელი. წინადადებას მარტივი წესები შლის,
  ამიტომ რთული ფრაზები და ქართული ხმოვანი ამოცნობა შეიძლება ვერ იმუშაოს.
  შესაძლებელია ტექსტის ხელით შეყვანაც.
- შეხსენებები მუშაობს მხოლოდ აპლიკაციის გახსნისას და არა დახურულ ფონში;
  ასევე არ გვაქვს მგზავრობის დროის ავტომატური გათვლა.
- მონაცემები ინახება ამ მოწყობილობის ამ ბრაუზერის localStorage-ში;
  არ არის მომხმარებლის ანგარიში, cloud, ან სხვადასხვა ტელეფონის სინქრონი.
- ამ ეტაპზე არ არის PIN ან ბიომეტრიული დაცვა. ფინანსური მონაცემებისთვის
  მომხმარებელმა უნდა გამოიყენოს დაცული ტელეფონი და ექსპორტის ფაილიც დაიცვას.
- ეს არის საწყისი ვებ/PWA პროტოტიპი, არა Android APK/AAB.
- Google Play-ის ვერსიას დასჭირდება ცალკე Android შეფუთვა/აპლიკაციის პროექტი.
- AI IA სახელის სავაჭრო ნიშანი/უნიკალურობა ჯერ მოსაკვლევია.

შემდეგი ეტაპები: რეალური AI ხმოვანი ბრძანებები, Android background alarms,
გზის სავარაუდო დრო, Cloud sync, PIN/biometric, მრავალვალუტიანი რეპორტები.


====== განახლება 0.2 ======
1. მთავარ ეკრანზე ყველაზე ზემოთ ჩნდება დღევანდელი მისამართები, საათები და Google Maps-ის ღილაკები.
2. ფინანსებზე ჩანს მიმდინარე თვის შემოსავალი, ხარჯი, ნაშთი და ხარჯების კატეგორიები. შესაძლებელია თვის შეცვლა.
3. ხმოვანი/ტექსტური ბრძანება „მაჩვენე ამ თვის ფინანსური შედეგი“ ხსნის ფინანსების გვერდს.
4. ბრძანება „წაშალე ხვალინდელი შეკვეთა“ არჩევს შესაბამის ჩანაწერს და სთხოვს დადასტურებას.
5. მიკროფონით ნათქვამის ამოცნობის შემდეგ ავტომატურად მუშავდება ბრძანება. ჩანაწერების შენახვას მაინც სჭირდება დადასტურება.
6. მთავარი გვერდიდან აპის დაყენების ინსტრუქცია, Chrome-ის პირობების შესაბამისად.
შენიშვნა: ეს არის საცდელი PWA, არა APK; ხმოვანი ამოცნობა ბრაუზერის მხარდაჭერაზეა დამოკიდებული. ფონური push ჯერ არ მუშაობს.
