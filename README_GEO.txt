AI IA — ვერსია 0.3 (დაყენების გასწორება)
=======================================

ZIP-ში ყველა ასატვირთი ფაილი პირდაპირ მთავარ დონეზეა — icons საქაღალდე აღარ არის საჭირო.

GitHub-ზე განახლება:
1. ZIP ამოარქივე.
2. AI-IA რეპოზიტორია გახსენი > Add file > Upload files.
3. ატვირთე ყველა ფაილი: index.html, styles.css, app.js, sw.js,
   manifest.webmanifest, favicon.png, icon-192.png, icon-512.png,
   icon-maskable-512.png. (README_GEO.txt სურვილისამებრ.)
4. Commit changes. თუ შეცვლას გთხოვს, დაადასტურე, რომ ძველი ფაილები ჩანაცვლდეს.
5. Settings > Pages გადაამოწმე: main / (root). HTTPS-ზე უნდა იხსნებოდეს.
6. გახსენი Chrome-ში თვითონ საიტის ბმული, არა GitHub-ის ფაილის გვერდი.
7. ძველი AI IA მალსახმობი წაშალე მთავარი ეკრანიდან (მონაცემების წაშლის გარეშე).
8. Chrome: ⋮ → Add to Home screen → Install app / აპის ინსტალაცია.
   არ აირჩიო Create shortcut / მალსახმობის შექმნა.
9. აპის ხატულა უნდა გამოჩნდეს და Chrome-ის მისამართის ზოლი აღარ უნდა იყოს.

თუ მხოლოდ Create shortcut ჩანს, რეალური მისამართი და Chrome-ის მენიუს სქრინშოტი
გამოგზავნე: შესაძლოა ფაილი არ აიტვირთა, არასწორი URL გახსენი, ან ბრაუზერი
ჯერ ვერ აღიქვამს საიტს PWA-დ. დაყენების შეთავაზებას ზოგჯერ დრო სჭირდება.

მნიშვნელოვანი: ეს PWA ვებაპია და არა Android APK. ის Chrome-ის ძრავით მუშაობს,
მაგრამ წარმატებით დაყენების შემთხვევაში დამოუკიდებელ ფანჯარაში იხსნება.

უკვე არსებული შეხვედრები/ფინანსები localStorage-შია. სხვა მისამართზე ან
ბრაუზერში გადასვლით მონაცემები შეიძლება აღარ გამოჩნდეს; მანამდე გამოიყენე
აპის პარამეტრებიდან ექსპორტი / backup JSON. არ წაშალო Chrome-ის საიტის მონაცემები.

ვერსია 0.2-ის ყველა წინა შესაძლებლობა შენარჩუნებულია.
ფონური შეხსენებები და სრული AI ჯერ დამუშავების ეტაპზეა.
